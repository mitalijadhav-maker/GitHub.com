## 📝 How the To-Do List Works

### Local Storage Implementation
- Tasks are automatically saved to your browser's localStorage
- Tasks persist even after closing and reopening the browser
- Data is stored as JSON in the key `todos`

### Features
1. **Add Tasks**: Type in the input field and press Enter or click Add Task
2. **Complete Tasks**: Click the checkbox to mark tasks as done
3. **Delete Tasks**: Click the Delete button to remove a task
4. **Filter Tasks**: Use the filter buttons to view All, Active, or Completed tasks
5. **Clear Completed**: Remove all completed tasks at once
